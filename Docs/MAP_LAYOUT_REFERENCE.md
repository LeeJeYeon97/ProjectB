## 2레벨 시험 구성

- `MapLevel2`의 로컬 좌표에서 발판 중심은 `(-5, 15.2)`, `(-5, 19.2)`, `(1, 15.2)`, `(1, 19.2)`이며 각 값은 X, Z 순서다. 앞의 두 개는 PochaSeat1, 뒤의 두 개는 PochaSeat2다.
- PochaSeat1은 발판의 `SpawnPoint`를 로컬 X -1.95, Z +0.1로 보정해 테이블 외형 중심을 발판 근처에 맞춘다. 2레벨 해금 후 네 발판을 별도로 사용하며 각 가격은 시험용 100이다. 확정 밸런스가 아니다.
- 네 모서리의 작은 화분은 배치 확인용 장식이다. 중앙 공간을 통로로 비워 뒀으나 실제 손님·직원의 왕복과 상호작용 범위는 아직 검증하지 않았다.
- 격리 카메라로 해금 후 가구 외형을 확인했다. 기존 NavMesh에서 안쪽 두 발판 위치는 0.5 반경 샘플에 실패해 직원·손님이 갈 수 있다고 보장할 수 없다. NavMesh 보강과 실제 지불·동선 플레이 검증은 [DEV-025](BACKLOG.md)에 남긴다.
- MapLevel2의 활성 설정 및 이전에 사용자가 변경한 벽 구조를 보존한다. 3레벨 위치와 구조는 현재 시험 범위에 포함하지 않는다.
